# TraceClean Provenance Exposure Score Specification (v1.0)

The **Provenance Exposure Score** is a transparent, deterministic diagnostic aggregate (scaled from `0.0` to `100.0`) that measures the extent of detectable AI provenance marks, C2PA claims, EXIF/XMP metadata tags, and invisible steganographic carriers present in a file.

> [!IMPORTANT]
> ### Critical Disclaimers
> 1. **NOT AN AI PROBABILISTIC DETECTOR**: The Provenance Exposure Score measures the presence of *physical provenance signals & metadata tags*. It does **NOT** estimate the probability that a document or image was generated by AI.
> 2. **NOT A UNIVERSAL CLEANLINESS GUARANTEE**: A score of `0.0` means no known provenance signals were detected by the active inspection tools. It does not guarantee that content is free of unknown, proprietary, or un-inspected marks.
> 3. **INCONCLUSIVE MARKS CANNOT YIELD ZERO**: If required server tools (`c2patool`, `exiftool`, `qpdf`) are unavailable for a given file format, the assessment is marked `inconclusive`, and the score value is set to `null`.

---

## Formula & Derivation

The score calculation is a pure, deterministic in-memory function:

$$\text{Raw Exposure} = \sum_{f \in \text{Findings}} W(\text{category}_f) \times M(\text{severity}_f) \times C(\text{confidence}_f)$$

$$\text{Final Exposure Score} = \min\left(100.0, \, 100.0 \times \left(1 - e^{-\frac{\text{Raw Exposure}}{50.0}}\right)\right)$$

### 1. Category Base Weights $W$
- `c2pa`: **40.0** (Cryptographic content credentials manifest)
- `image_metadata`: **25.0** (Explicit AI generator software tags or EXIF fields)
- `document_metadata`: **25.0** (PDF/DOCX core properties, HTML meta tags)
- `invisible_text`: **30.0** (Zero-width spaces, bidi overrides, tag characters)
- `statistical_text`: **15.0** (Stylometric prose structure signals)

### 2. Severity Multipliers $M$
- `critical`: **1.0**
- `high`: **0.8**
- `medium`: **0.5**
- `low`: **0.25**
- `info`: **0.0**

### 3. Confidence Multipliers $C$
- `confirmed`: **1.0**
- `probable`: **0.75**
- `informational`: **0.3**
- `likely_false_positive`: **0.0**

---

## Inconclusive & Degraded Capability Rules

When required CLI inspection tools (`c2patool`, `exiftool`, `qpdf`) are missing for a file format:
- `verification_status` = `"inconclusive"`
- `score` = `null`
- `status_reason` = `"No marks detected by built-in parsers, but required tool(s) (c2patool, exiftool) were unavailable for full verification."`
- `verified_clean` = `false`

The system explicitly refuses to emit a score of `0.0` when inspection coverage is incomplete.
